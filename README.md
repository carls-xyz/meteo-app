# meteo-app

Squelette d'une application météo en **PHP**, initialisée avec [Guzzle](https://docs.guzzlephp.org/) pour interroger une API météo.

## État du projet

Le projet est au stade de l'initialisation : seules les dépendances Composer sont en place. Le code applicatif (appel de l'API, affichage des prévisions) reste à écrire.

## Installation

```bash
composer install
```

## Dépendances

- `guzzlehttp/guzzle` ^7.9 : client HTTP pour appeler l'API météo
